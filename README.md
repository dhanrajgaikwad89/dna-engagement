# Apeksha & Dhanraj — DnA

Our engagement, 28 May 2026.

Live website: https://dhanrajgaikwad89.github.io/dna-engagement/

A responsive keepsake with 49 photographs, interactive photo frames, a slideshow, our story, four engagement films and an optional love-song player featuring Alfaaz, Kesariya and Din Shagna Da.

## Hosting and updates

This is a static HTML, CSS and JavaScript website. GitHub Pages publishes the root of the main branch. No build step is needed.

Edit index.html for page content, styles.css for presentation, app.js for interactions and songs, and photos.js for gallery metadata. Keep assets at their relative paths.

Photographs and personal content belong to their respective owners. YouTube videos remain hosted on YouTube; playback depends on the video owner's embed settings.
